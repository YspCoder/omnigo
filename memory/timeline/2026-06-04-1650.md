# Reason
用户希望把 Pai 官方文档中的一些独立能力一并接入，而不仅限于基础文生/图生/首尾帧。

# Important Decisions
- 这次优先接入仍然符合“异步视频任务”模型的能力，继续复用统一 `Media` / `TaskStatus`
- `swap` 只接生成接口，`mask/selection` 作为前置辅助接口暂不自动接入
- `lip-sync` 同时支持音频素材路径和 TTS 字段透传

# Risks
- `swap` 仍依赖调用方准备 `mask_id`
- `lip-sync` / `extend` / `mimic` 的视频源仍需调用方提供 `source_video_id` 或 `video_media_id`
- `sound_effect`、`restyle`、`modify` 等能力这次未接入
