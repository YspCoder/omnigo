# Reason
需要让 `omnigo` 支持拍我AI官方开放平台的任务型视频接口，并复用现有统一 provider 抽象。

# Important Decisions
- `pai` 首版按官方文档落地三个高频能力：文生视频、图生视频、首尾帧
- 统一自动生成 `Ai-Trace-Id`，避免调用方漏传导致重复请求不生效
- 图生/首尾帧模式优先接受已存在的 `img_id`，没有时自动上传图片
- 先不实现 `ListTasks`，因为官方文档当前没有稳定任务列表接口

# Risks
- 官方还有 `extend`、`swap`、`mimic`、`multi-transition` 等接口，当前未接入
- `Ai-Trace-Id` 现在由 SDK 内部生成；如果业务方需要幂等控制，后续可能要暴露覆盖能力
- 首尾帧当前只自动使用前两张图，更多复杂多图玩法还未支持

# Next Possible Steps
- 增加 `extend`、`swap`、`mimic` 等更多 Pai 视频能力
- 暴露自定义 `Ai-Trace-Id` / 上传复用策略
- 为 `pai` 增加真实环境 smoke test
